# ShopWave iOS

SwiftUI app for the ShopWave e-commerce platform.

## Requirements
- Xcode 16+
- iOS 17+ deployment target
- Swift 5.10

## Architecture
MVVM + Coordinator pattern. Each feature module owns its ViewModel, View, and Coordinator.

## Quick Start
```bash
open ShopWave.xcodeproj
# Set your development team in Signing & Capabilities
# Run on simulator or device
```
